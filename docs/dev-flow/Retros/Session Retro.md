# Session Retro

End-of-session check-in. 4-5 prompts. Catch lessons before they evaporate.

| Signal | Memory Type |
|--------|-------------|
| Recurring user preference | user |
| Correction received | feedback |
| Project-specific gotcha | project |
| External fact / link | reference |
| Repo-level runbook tip | napkin / CLAUDE.md |

**Prompts**
1. What surprised me this session?
2. What assumption was wrong, and what corrected it?
3. What would I want loaded next time I touch this?
4. What belongs in long-term memory vs scratch?
5. What runbook entry would have saved 10 minutes?

**Output discipline**
- Each saved item = one signal, one type
- If it's not reusable, don't save it
- Prefer napkin for repo-scoped tips, CLAUDE.md for cross-repo norms

Skip retro = repeat mistake. Two minutes now beats hour later.
